# 🎓 SkillSphere – Online Learning Platform

SkillSphere is a modern, responsive, and high-performance online learning platform built with **Next.js**. It allows users to explore a wide range of skill-based programs, from Web Development to Marketing, featuring a premium user experience with smooth animations and a secure authentication system.

**Live URL:** [https://assignment-08-ruddy.vercel.app/]
**Repo link**[https://github.com/raidibney/ASSIGNMENT_08]
---

## 🚀 Key Features

*   **Premium UI/UX:** A clean, modern design built with **Tailwind CSS** and **HeroUI**, featuring smooth page transitions and a professional dark aesthetic.
*   **Dynamic Course Management:** Browse a curated list of courses with advanced filtering and a real-time **Search Functionality** (search by title).
*   **Secure Authentication:** Integrated **BetterAuth** supporting Email/Password and **Google Social Login**.
*   **Protected Routes:** Private access to Course Details and User Profile pages.
*   **Interactive My Profile:** Dedicated user dashboard where students can view their info and update their **Name** and **Profile Picture**.
*   **Modern Animations:** Utilizing **Framer Motion** for a dynamic and engaging layout.
*   **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop views.
*   **Persistence:** Persistent Navbar and Footer across all routes using the Next.js App Router.
