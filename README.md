# 🎓 SkillSphere – Online Learning Platform

SkillSphere is a modern, responsive, and high-performance online learning platform built with **Next.js**. It allows users to explore a wide range of skill-based programs, from Web Development to Marketing, featuring a premium user experience with smooth animations and a secure authentication system[cite: 1].

## 🚀 Key Features

*   **Premium UI/UX:** A clean, modern design built with **Tailwind CSS** and **HeroUI**, featuring smooth page transitions and a professional dark aesthetic[cite: 1].
*   **Dynamic Course Management:** Browse a curated list of courses with advanced filtering and a real-time **Search Functionality** (search by title)[cite: 1].
*   **Secure Authentication:** Integrated **BetterAuth** supporting Email/Password and **Google Social Login**[cite: 1].
*   **Protected Routes:** Private access to Course Details and User Profile pages[cite: 1].
*   **Interactive My Profile:** Dedicated user dashboard where students can view their info and update their **Name** and **Profile Picture**[cite: 1].
*   **Modern Animations:** Utilizing **Framer Motion** for a dynamic and engaging layout[cite: 1].
*   **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop views[cite: 1].
*   **Persistence:** Persistent Navbar and Footer across all routes using the Next.js App Router[cite: 1].
